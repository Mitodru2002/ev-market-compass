# ⚡ Electric Vehicle Market Analytics: Python & Power BI

> An end-to-end data analysis project exploring Electric Vehicle (EV) adoption dynamics. This repository combines rigorous exploratory data analysis (EDA) with an interactive business intelligence dashboard to uncover key consumer and infrastructure trends.

## 📌 Executive Summary
With the rapid electrification of the automotive industry, understanding adoption patterns is critical for policymakers, urban planners, and manufacturers. This project processes a comprehensive EV registration dataset using **Python** for cleaning and statistical insights, and builds a fully interactive **Power BI** dashboard featuring dynamic visual storytelling and custom brand metrics.

## 📂 Repository Architecture

| Component / File | Description |
| :--- | :--- |
| `Exploratory_Data_Analysis_of_Electric_Vehicle.ipynb` | Comprehensive Python notebook covering data wrangling, missing value treatment, and statistical EDA. |
| `major_project.pbix` | Interactive Power BI dashboard complete with custom slicers, drill-throughs, and dynamic styling. |
| `cleaned_ev_data.xlsx` | Processed, optimization-ready dataset structured for high-performance reporting. |
| `Electric_Vehicle_Population_Data.xlsx` | The raw, unfiltered dataset used as the foundation for the analysis. |

## 🔍 Key Analytical Insights
* **Geographic Penetration:** Mapped high-density adoption corridors and analyzed the urban vs. rural divide in EV registrations.
* **Manufacturer Dominance:** Evaluated market share concentrations and growth trajectories among the top industry leaders.
* **Powertrain Breakdown:** Comparative analysis of Battery Electric Vehicles (BEVs) versus Plug-in Hybrid Electric Vehicles (PHEVs).
* **Infrastructure Correlation:** Assessed how regional utility providers and CAFV eligibility impact localized EV growth speeds.

## 🛠️ Tech Stack & Tooling
* **Programming & Core Analysis:** Python (Pandas, NumPy, Matplotlib, Seaborn via Jupyter/Google Colab)
* **Data Visualization & BI:** Power BI, DAX Measures
* **Data Preprocessing:** Microsoft Excel
* **Design & Asset Workflow:** Generative AI tools (DeepAI, Google Gemini) for custom branding assets and vector icons.
